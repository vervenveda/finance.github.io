ARSHIF Financial Hall — Certification Portal
A sovereign, local-first financial education portal built as a single-file vanilla HTML/CSS/JavaScript application. The portal is designed for learners, families, artists, entrepreneurs, homeschool programs, community builders, and self-directed adults who want a structured path through money literacy, consumer protection, budgeting, credit, debt, investing literacy, taxes, insurance, fraud prevention, ethics, and long-term stewardship.

Important boundary: This project provides general financial education only. It is not individualized investment, tax, legal, insurance, benefits, accounting, or financial-adviser advice. The certificate generated by the portal is an ARSHIF Certificate of Completion, not an accredited degree, government license, securities license, tax-preparer credential, or professional financial-planning credential.

Privacy and Local Storage
This portal is designed to be local-first. Learner progress, notes, scores, capstone work, vault records, and saved data are stored in the browser using local storage unless exported by the user.

Do Not Upload Private Records
When publishing this project to GitHub, upload only the public portal files.

Student Vault and Backup Guidance
The Student Vault supports:

Exporting a learner record as JSON
Importing that record on another computer
Exporting an encrypted vault with a passphrase
Importing the encrypted vault later
Creating emergency snapshots
Restoring recovery snapshots
For dual-computer access, use this rhythm:

Complete learning work on Computer A.
Export the Student Record JSON or encrypted vault.
Save it to a trusted private storage location.
Open the portal on Computer B.
Import the latest vault file.
Continue work.
Export again at the end of the session.
This is not cloud sync. It is a portable backup workflow.

GitHub Pages Setup
To publish this portal using GitHub Pages:

Create a new GitHub repository.
Add the upgraded portal file.
Rename the portal file to index.html if this repository will host only this portal.
Add this README.md file.
Add a LICENSE.md file if needed.
Go to Settings → Pages.
Choose the branch, usually main.
Choose the root folder or /docs folder.
Save and wait for GitHub Pages to build.
Test the portal in a private browser window.
